# TerminalChat-Serverless-Encrypted-Mesh-Chat
Program obrolan konsol terminal yang dikembangkan secara terintegrasi di atas infrastruktur REST API. Aplikasi ini mengimplementasikan kriptografi militer AES-256-GCM guna memastikan kerahasiaan komunikasi tanpa membutuhkan manajemen server terpusat yang rentan terhadap kebocoran log data atau serangan pelacakan IP.
